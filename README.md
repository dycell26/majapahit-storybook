# 📖 Majapahit Storybook

**Majapahit Storybook** adalah storybook interaktif berbasis web yang menceritakan sejarah dan kejayaan Kerajaan Majapahit dengan tampilan visual modern, mobile-first, dan mudah diakses.

Project ini dibuat **tanpa backend, tanpa AI, dan tanpa framework berat**, sehingga aman untuk publik dan langsung bisa dijalankan di GitHub Pages.

---

## ✨ Fitur Utama

- 📱 **Mobile-first design (9:16)** – optimal untuk smartphone
- 🖼️ **Visual story dengan gambar penuh**
- 🎬 **Animasi halus & transisi halaman**
- 📚 **Navigasi cerita interaktif**
- 🌐 **Static HTML (tanpa server)**
- 🚀 **Siap deploy ke GitHub Pages**

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**
- **Tailwind CSS (CDN)**
- **Vanilla JavaScript**
- **Google Fonts**
- **Lucide Icons**
- **GitHub Pages**

## 📦 Cara Menjalankan (Local)

1. Download / clone repository
2. Buka file `index.html`
3. Jalankan langsung di browser (Chrome / Edge / Firefox)

> Tidak memerlukan server atau instalasi tambahan

---

## 🌍 Cara Deploy ke GitHub Pages

1. Upload `index.html` ke repository
2. Masuk ke **Settings → Pages**
3. Pilih:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. Klik **Save**
5. Tunggu ±30 detik

Website akan aktif otomatis.

---

## 🖼️ Catatan Gambar

- Gambar menggunakan **direct image URL** (contoh: Imgur `.jpg`)
- Tidak membutuhkan parameter tambahan seperti `?w=600`
- Aman untuk static hosting
